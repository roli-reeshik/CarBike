1. System Workflow & Hybrid Caching Architecture

How 95%+ of dynamic traffic is served instantly without database bottleneck.

Zero-Egress Cost Model
flowchart TD Visitor[Incoming Visitor] --> CDN[Global CDN / Edge Cache] CDN -- 95% Traffic (Hit) --> Cached[Cached Static HTML / ISR Revalidated] CDN -- Images/Media (0$ Egress) --> CloudflareR2[Cloudflare R2 / Object Storage] CDN -- Cache Miss / Dynamic Filters --> Serverless[Next.js Serverless Function / Route Handler] Serverless --> DB[(Local / Managed PostgreSQL DB)] subgraph Data Pipeline Scraper[Python Playwright Scraper] --> AssetStorage[public/vehicles/ & Image CDN] Scraper --> SeedData[prisma/scraped_seed_data.json] SeedData --> PrismaSeed[Prisma ORM Ingestion] PrismaSeed --> DB end

Technology Stack Specification

Frontend Layer Next.js 15 (App Router, Server Components), TypeScript, Tailwind CSS, Lucide Icons, Framer Motion
Database & ORM PostgreSQL (Relational engine) with Prisma ORM (Indexed queries on body types, slugs, budget slabs)
State & Performance Zustand (Persistent comparison dock), Incremental Static Regeneration (revalidate = 3600)
Media Pipeline Cloudflare R2 Object Storage / Local Public Folder with Next.js Image Optimization
Data Sourcing Engine Python 3.x, Playwright (Headless Chromium), AsyncIO, AioHTTP for parallel high-res asset scraping

2. PostgreSQL & Prisma Database Schema

Supports variants, color swatches, upcoming lifecycle states, and lead capture.

prisma/schema.prisma
Prisma Schema Configuration PostgreSQL Syntax 
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

generator client {
  provider = "prisma-client-js"
}

enum VehicleType {
  CAR
  BIKE
}

enum LaunchStatus {
  UPCOMING
  PRE_BOOKING_OPEN
  LAUNCHED
  DISCONTINUED
}

enum LeadType {
  OFFER
  TEST_DRIVE
  LAUNCH_ALERT
}

model Brand {
  id          String      @id @default(cuid())
  name        String      @unique
  slug        String      @unique
  logoUrl     String?
  vehicleType VehicleType
  vehicles    Vehicle[]
  createdAt   DateTime    @default(now())
}

model Vehicle {
  id                   String        @id @default(cuid())
  brandId              String
  brand                Brand         @relation(fields: [brandId], references: [id], onDelete: Cascade)
  name                 String
  slug                 String        @unique
  category             VehicleType
  tagline              String?
  bodyType             String        // Hatchback, Sedan, Compact SUV, etc.
  fuelTypes            String[]      // Petrol, Diesel, EV, CNG
  transmissionTypes    String[]      // Manual, Automatic
  heroImage            String
  priceMin             Decimal       @db.Decimal(10, 2)
  priceMax             Decimal       @db.Decimal(10, 2)
  budgetRange          String
  ncapRating           Int?
  
  // Upcoming Vehicle Lifecycle Fields
  launchStatus         LaunchStatus  @default(LAUNCHED)
  expectedLaunchDate   String?
  isDateConfirmed      Boolean       @default(false)
  expectedPriceMinLakh Decimal?      @db.Decimal(10, 2)
  expectedPriceMaxLakh Decimal?      @db.Decimal(10, 2)
  preBookingAmount     String?
  spyShotGallery       String[]      @default([])

  // Engine Specs
  engineOrBattery      String
  powerBhp             String
  torqueNm             String
  mileageOrRange       String
  groundClearanceMm    Int?
  seatingCapacity      Int?          // 5, 7 for Cars
  bikeStyle            String?       // Commuter, Cruiser, Sport for Bikes

  variants             Variant[]
  colors               VehicleColor[]
  dealers              Dealer[]
  reviews              Review[]
  leads                Lead[]

  createdAt            DateTime      @default(now())
  updatedAt            DateTime      @updatedAt

  @@index([category, bodyType])
  @@index([category, budgetRange])
  @@index([launchStatus])
}

model Variant {
  id               String   @id @default(cuid())
  vehicleId        String
  vehicle          Vehicle  @relation(fields: [vehicleId], references: [id], onDelete: Cascade)
  name             String
  exShowroomPrice  Decimal  @db.Decimal(10, 2)
  onRoadPriceEst   Decimal  @db.Decimal(10, 2)
  transmission     String
  keyFeatures      String[]
  createdAt        DateTime @default(now())
}

model VehicleColor {
  id         String   @id @default(cuid())
  vehicleId  String
  vehicle    Vehicle  @relation(fields: [vehicleId], references: [id], onDelete: Cascade)
  name       String
  hexCode    String
  previewUrl String
}

model Dealer {
  id         String   @id @default(cuid())
  vehicleId  String
  vehicle    Vehicle  @relation(fields: [vehicleId], references: [id], onDelete: Cascade)
  name       String
  city       String
  address    String
  phone      String
  rating     Decimal  @default(4.5) @db.Decimal(3, 1)

  @@index([city])
}

model Review {
  id             String   @id @default(cuid())
  vehicleId      String
  vehicle        Vehicle  @relation(fields: [vehicleId], references: [id], onDelete: Cascade)
  authorName     String
  city           String
  ratingOverall  Int
  title          String
  comment        String
  isVerified     Boolean  @default(true)
}

model Lead {
  id         String     @id @default(cuid())
  userName   String
  phone      String
  city       String
  vehicleId  String
  vehicle    Vehicle    @relation(fields: [vehicleId], references: [id], onDelete: Cascade)
  leadType   LeadType   @default(OFFER)
  createdAt  DateTime   @default(now())
}

3. Automated Playwright Scraper Pipeline

Directly extracts HD media to public/vehicles/ and seeds prisma/scraped_seed_data.json.

scripts/scraper.py

Automobile OEM homepages rely heavily on geo-location modals and dynamic video headers. The robust solution uses canonical product endpoints and uncaps CDN image resolution:

Supported Car Endpoints

  • Tata Motors: Nexon, Punch, Curvv, Harrier (ICE/EV)
  • Maruti Suzuki: Brezza, Swift, Dzire, Ertiga
  • Mahindra Auto: XUV700, Thar, Scorpio-N
  • Hyundai India: Creta, Venue

Supported Bike Endpoints

  • Royal Enfield: Classic 350, Hunter 350, Himalayan 450
  • TVS Motor: Raider 125, Apache RTR 160 4V
  • Hero MotoCorp: Splendor Plus, Xtreme 125R
HD Un-capping Algorithm: Automatically parses srcset to select the highest resolution width (e.g. 2000w) and strips query downscaling parameters like ?w=400&q=50 to force 100% master quality downloads.
